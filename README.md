# 異界補給戦記 ― 補給事務トレーニング

補給・物流の書類仕事を、ゲームで学ぶための教材です。
書いた書類は書いたとおりに届き、書き損じは戦闘や店舗の営業、配達の結果にそのまま響きます。

**遊ぶ：** https://＜ユーザー名＞.github.io/＜リポジトリ名＞/

## 特長

- **研修シナリオは3種類**
  - 派遣補給隊（異世界）：前線へ物資を送り、魔物と戦う
  - 物流倉庫モード：物流センターから店舗へ出荷し、店舗の営業で結果を見る
  - 宅配中継モード：送り状を書き、温度帯（常温・冷蔵・冷凍）に気をつけて配達する
- **立場は3種類**
  - 補給所：依頼書を読んで払出票（出荷伝票・送り状）を書く
  - 中継地点：届いた書類を、依頼書・現品・一覧表と照合し、通すか差し戻すか判断する
  - 前線：必要な物と数を見積もって請求書を書き、届いた物を受領確認する
- **難易度は3段階**
  - 簡単：赤枠ガイドあり、時間制限なし、やり直しができる
  - 普通：制限時間3分
  - 難しい：制限時間2分、在庫にも余裕がない
- 払出票を3枚複写で出し、原本・中継控え・補給所控えがそれぞれどこへ行くのかを確かめる「書類の行方」
- 査閲報告（業務報告）で、どの書き損じが結果にどう響いたかを振り返る
- BGM・効果音つき。画面左下でオン・オフできる

## 動かし方

`index.html` を1つ開くだけで動きます。インストールは不要です。

- **ブラウザで直接開く**：`index.html` をダブルクリックする
- **GitHub Pages で公開する**：リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして保存する
- **社内サーバーに置く**：`index.html` をそのまま置く

### 動作環境

- Chrome・Edge・Safari・Firefox の最新版（パソコン推奨。タブレットでも動きます）
- 文字の書体は Google Fonts から読み込みます。インターネットにつながっていない環境では、パソコンにある明朝体で表示されます（遊ぶことはできます）
- 自己ベストと音の設定は、ブラウザに保存されます
